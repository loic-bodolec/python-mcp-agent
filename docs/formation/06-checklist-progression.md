# 06 - Checklist de progression

## Niveau 1 : compréhension

- [ ] On sait expliquer le rôle de Groq.
- [ ] On sait expliquer le rôle de wttr.in.
- [ ] On sait expliquer le rôle de pytz.
- [ ] On comprend le flux question -> tool -> LLM.

## Niveau 2 : exécution

- [ ] On lance le projet en local sans aide.
- [ ] On configure `.env` correctement.
- [ ] On active/désactive DEBUG selon le besoin.
- [ ] On teste météo, heure et question générale.

## Niveau 3 : modification

- [ ] On ajoute un mot-clé de détection.
- [ ] On ajoute un nouveau tool simple.
- [ ] On garde des messages d'erreur propres.
- [ ] On met à jour le README après un changement.

## Niveau 4 : qualité

- [ ] Le code reste lisible (fonctions courtes, noms clairs).
- [ ] Les dépendances sont cohérentes avec le code.
- [ ] Les régressions sont vérifiées rapidement.
- [ ] Les limites connues sont documentées.

## Niveau 5 : autonomie

- [ ] On peut transformer ce mini-projet en assistant métier.
- [ ] On peut brancher d'autres APIs (news, stocks, maps, etc.).
- [ ] On peut exposer les tools via MCP pour un autre agent.
- [ ] On peut expliquer ce projet à un débutant en 5 minutes.
