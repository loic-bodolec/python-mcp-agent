## Objectif pédagogique

À l'issue du parcours, on sait :

- expliquer la différence entre un LLM et un tool
- concevoir une logique conditionnelle tool/no-tool
- brancher une API externe dans un agent
- exposer des tools via MCP
- déboguer un agent local avec un mode DEBUG

## Prérequis

- Python 3.10+
- bases de terminal (activer un venv, lancer un script)
- bases Python (fonctions, dictionnaires, `try/except`)
